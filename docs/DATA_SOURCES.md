# Data and attribution

Phase 0 includes no datasets, external feed calls, generated forecasts, training or resume processing. The compass illustration is original CSS. Icons: lucide-react (ISC); React, Vite, Tailwind CSS, React Router, TanStack Query, Radix Slot and shadcn/ui conventions (MIT). Backend libraries retain their upstream licenses. shadcn-style primitives are local code rather than a separate component library.

Planned sources, subject to verification before ingestion:

- Indeed Hiring Lab: https://github.com/hiring-lab/job_postings_tracker — country/sector posting indices; inspect dataset-specific terms and temporal coverage.
- WEF Future of Jobs 2025: https://www.weforum.org/publications/the-future-of-jobs-report-2025/ — long-run context, not a statistical forecast of 2030 jobs.
- O*NET: https://www.onetcenter.org/database.html — verify attribution and license for each downloaded artifact.
- United Nations SDGs and official targets: https://sdgs.un.org/goals — use direct official goal/target citations for future mappings.

These are planned references, not evidence ingested or validated by this application. Record exact dataset URLs, licensing, geography, granularity, publication/retrieval dates and transformations before using any source. No cross-geography substitution or skill-level time-series inference is permitted without explicit limitations.
